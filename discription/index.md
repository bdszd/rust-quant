# Rust Quant

## 项目介绍

一个基于 Rust 构建的量化回测与交易系统。

项目目标：

- 构建可靠的回测引擎
    
- 构建可扩展的交易系统
    
- 提供 Web 可视化界面
    
- 后续集成 AI 分析能力
